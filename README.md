# ⚡ Бот «Графіки ГПВ Черкаси»

Бот стежить за каналом [АТ «Черкасиобленерго»](https://t.me/pat_cherkasyoblenergo).
Коли там з'являється графік погодинних відключень, бот робить з нього **картинку-таблицю й короткий текст** і одразу публікує їх у всі підключені канали, групи та особисті чати.

- Бот один на всіх. Друзі не встановлюють нічого свого: вони просто додають вашого бота у свій канал чи групу або пишуть йому `/start`.
- Канал-джерело бот читає через публічну веб-версію `t.me/s/...` і перевіряє її раз на хвилину. Ваш акаунт для цього не потрібен.
- Якщо обленерго відредагує пост, бот надішле «🔄 Оновлений графік».

---

## 1. Створити бота (5 хв, з айфона)

1. Відкрийте [@BotFather](https://t.me/BotFather), надішліть `/newbot` і придумайте ім'я та username.
2. Скопіюйте **токен** виду `123456:ABC...`.
3. Дізнайтеся свій Telegram ID у [@userinfobot](https://t.me/userinfobot). Він потрібен, щоб бот знав власника (див. «Приватний режим»).

## 2. Орендувати сервер (VPS)

Бот має працювати 24/7, тому **ноутбук не підходить**. Підійде найдешевший VPS:
Hetzner CX22 (~4 €/міс), DigitalOcean, Contabo тощо. Система: **Ubuntu 24.04**.

Підключитися до сервера можна з Mac через `ssh root@IP_СЕРВЕРА` або з айфона через застосунок Termius.

## 3. Запустити (3 команди)

```bash
# один раз: встановити Docker
curl -fsSL https://get.docker.com | sh

# скопіювати проєкт на сервер (з Mac):
#   rsync -av --exclude .venv --exclude .idea --exclude .junie --exclude .pytest_cache ~/Desktop/GVSTelegramBot root@IP_СЕРВЕРА:/root/
cd /root/GVSTelegramBot
cp .env.example .env && nano .env      # вставити BOT_TOKEN та OWNER_ID

docker compose up -d --build
```

Логи: `docker compose logs -f`. Оновлення після змін коду: `docker compose up -d --build`.

## 4. Підключити канал і чат

- **Канал:** Налаштування каналу → Адміністратори → Додати адміністратора → ваш бот (право «Публікувати повідомлення»).
- **Група:** просто додайте бота в учасники, і він підключиться сам.
- **Особисто:** напишіть боту `/start`.

Після підключення бот одразу публікує туди актуальний графік (на сьогодні й завтра, якщо вже є) і пише вам в особисті «✅ Підключено».

## Приватний режим (доступ лише за вашим дозволом)

Бот працює **тільки для тих, кому ви дозволили**. Знайти його в пошуку Telegram може будь-хто, але:

- незнайомець натискає Start → бот відповідає «🔒 Бот приватний, запит надіслано», а вам приходить
  «🔔 Запит на доступ» з кнопками **✅ Дозволити / ❌ Відхилити**;
- після «Дозволити» друг одразу отримує вітання й підписку на графіки;
- якщо бота в канал чи групу додає людина без доступу — бот одразу звідти виходить;
- `/users` — список: хто чекає, хто має доступ, хто відхилений, з кнопками
  «🚫 Забрати доступ» (бот вимкне підписку й вийде з груп/каналів, куди цю людину додала) та «✅ Дозволити».

Приватний режим працює, коли в `.env` задано `OWNER_ID`. Якщо `OWNER_ID=0` — бот відкритий для всіх.

**Кілька власників:** перелічіть ID через кому — `OWNER_ID=111111111,222222222`. Запити на доступ приходять
усім власникам, вирішити може будь-хто з них, і повідомлення з запитом оновиться в усіх. Кожен власник має
один раз натиснути Start у боті, інакше бот не зможе йому написати.

## Що сказати друзям

> Напиши боту @ваш_бот `/start` — я підтверджу доступ, і графіки приходитимуть тобі в особисті.
> Хочеш у свій канал чи групу? Після `/start` бот дасть кнопки «у канал» / «у групу».

## Команди

| Команда | Що робить |
|---|---|
| `/start` | підписатися + посилання, як додати бота в канал/групу |
| `/now` | графік на сьогодні (і на завтра, якщо вже опубліковано) |
| `/stop` | відписатися (у групах тільки для адмінів) |
| `/stats` | кількість підключених чатів і стан перевірок (лише власник) |
| `/users` | хто має доступ / чекає, кнопки дозволити й забрати (лише власник) |
| `/post` | опублікувати актуальний графік у вибраний канал чи групу — кнопками (лише власник, в особистому чаті з ботом) |

## Для розробки (Mac)

```bash
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
.venv/bin/python -m pytest -q        # тести
.venv/bin/python -m bot.render_demo  # demo.png з останнього графіка
.venv/bin/python -m bot.main         # запуск бота локально (потрібен .env)
```

Структура: `bot/scraper.py` читає канал, `parser.py` розбирає текст, `render.py` малює картинку,
`formatter.py` формує підпис, `publisher.py` перевіряє канал і робить розсилку, `handlers.py` обробляє команди,
`storage.py` працює з SQLite (`data/bot.db`).
