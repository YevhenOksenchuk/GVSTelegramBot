# ⚡ Бот «Графіки ГПВ Черкаси»

Бот стежить за каналом [АТ «Черкасиобленерго»](https://t.me/pat_cherkasyoblenergo).
Коли там з'являється графік погодинних відключень, бот робить з нього **картинку-таблицю й короткий текст** і одразу публікує їх у всі підключені канали, групи та особисті чати.

- Бот один на всіх. Друзі не встановлюють нічого свого: вони просто додають вашого бота у свій канал чи групу або пишуть йому `/start`.
- Канал-джерело бот читає через публічну веб-версію `t.me/s/...` і перевіряє її раз на хвилину. Ваш акаунт для цього не потрібен.
- Якщо обленерго відредагує пост, бот надішле «🔄 Оновлений графік».

---

## 1. Створити бота (5 хв, з айфона)

1. Відкрийте [@BotFather](https://t.me/BotFather), надішліть `/newbot` і придумайте ім'я та username.
2. Скопіюйте **токен** виду `123456:ABC...`.
3. Дізнайтеся свій Telegram ID у [@userinfobot](https://t.me/userinfobot). Він потрібен, щоб бот знав власника (див. «Приватний режим»).

## 2. Орендувати сервер (VPS)

Бот має працювати 24/7, тому **ноутбук не підходить**. Підійде найдешевший VPS:
Hetzner CX22 (~4 €/міс), DigitalOcean, Contabo тощо. Система: **Ubuntu 24.04**.

Підключитися до сервера можна з Mac через `ssh root@IP_СЕРВЕРА` або з айфона через застосунок Termius.

## 3. Запустити (4 команди на сервері)

```bash
curl -fsSL https://get.docker.com | sh                        # один раз: Docker
git clone https://github.com/YevhenOksenchuk/GVSTelegramBot.git /root/GVSTelegramBot
cd /root/GVSTelegramBot && cp .env.example .env && nano .env   # вставити BOT_TOKEN та OWNER_ID
./deploy.sh                                                   # збірка і запуск
```

Логи: `docker compose logs -f` (вийти — Ctrl+C, бот працює далі).

**Оновлення після змін коду** — одна команда на сервері:
```bash
/root/GVSTelegramBot/deploy.sh
```
Вона забирає код з GitHub (`git pull`), перезбирає й перезапускає бота, прибирає старі Docker-образи та показує
останні логи. База `data/bot.db` і `.env` не чіпаються. Яка версія зараз працює — показує `/stats`.

## 4. Підключити канал і чат

- **Канал:** Налаштування каналу → Адміністратори → Додати адміністратора → ваш бот (право «Публікувати повідомлення»).
  Щоб бот ще й **закріплював** актуальний графік і міг виправляти вже опубліковане (`/fix`), додайте право
  «Редагувати повідомлення інших».
- **Група:** просто додайте бота в учасники, і він підключиться сам. Для закріплення — право «Закріплювати повідомлення».
- **Особисто:** напишіть боту `/start`.

Після підключення бот одразу публікує туди актуальний графік (на сьогодні й завтра, якщо вже є) і пише вам в особисті «✅ Підключено».

## Приватний режим (доступ лише за вашим дозволом)

Бот працює **тільки для тих, кому ви дозволили**. Знайти його в пошуку Telegram може будь-хто, але:

- незнайомець натискає Start → бот відповідає «🔒 Бот приватний, запит надіслано», а вам приходить
  «🔔 Запит на доступ» з кнопками **✅ Дозволити / ❌ Відхилити**;
- після «Дозволити» друг одразу отримує вітання й підписку на графіки;
- якщо бота в канал чи групу додає людина без доступу — бот одразу звідти виходить;
- `/users` — список: хто чекає, хто має доступ, хто відхилений, з кнопками
  «🚫 Забрати доступ» (бот вимкне підписку й вийде з груп/каналів, куди цю людину додала) та «✅ Дозволити».

Приватний режим працює, коли в `.env` задано `OWNER_ID`. Якщо `OWNER_ID=0` — бот відкритий для всіх.

**Кілька власників:** перелічіть ID через кому — `OWNER_ID=111111111,222222222`. Запити на доступ приходять
усім власникам, вирішити може будь-хто з них, і повідомлення з запитом оновиться в усіх. Кожен власник має
один раз натиснути Start у боті, інакше бот не зможе йому написати.

## Моя черга і нагадування (лише для власників)

`/my` в особистому чаті з ботом: оберіть свою підчергу — і в кожному графіку першим рядком буде
«💡 Ваша 3.2: 12:00–14:00 · 19:00–21:00». Бот нагадає за **30 / 20 / 15 / 10 хв** (на вибір) до відключення:
«⚠️ Черга 3.2: о 19:00 вимкнуть світло (до 21:00). Через 28 хв.», а коли світло має з'явитися —
«💡 … за графіком світло має з'явитися о 21:00. Наступне відключення о 23:00.» (можна вимкнути).
Якщо обленерго оновило графік і відключення, про яке вже попередили, зникло — прийде «✅ … прибрали з графіка».
Нагадування рахуються з найсвіжішої версії графіка і не дублюються після перезапуску бота.

## Нагадування в каналах і групах

`/remind` (лише власники, в особистому чаті з ботом): для кожного каналу чи групи окремо вмикається нагадування за
**30 / 20 / 15 / 10 хв** до відключення. Усі черги, що вимикаються в один час, збираються в одне повідомлення:

> ⚡ **Черги 1.2, 3.1, 4.1, 6.2** — без світла через 10 хв
> Електроенергія буде відсутня з 10:00 до 12:00
> 📋 Переглянути актуальний графік

Посилання веде на останній графік бота в цьому ж чаті. Якщо обленерго оновить графік і додасть ще чергу на той
самий час, бот дошле окреме нагадування лише про неї. За замовчуванням нагадування в чатах вимкнені.

## Закріплення, виправлення, оголошення

- **Закріплення.** У каналах і групах бот тихо (без сповіщення) закріплює кожен новий графік і знімає своє попереднє
  закріплення. Якщо прав немає — один раз напише власникам. Вимкнути для окремого чату: `/pin`.
- **`/fix`.** Якщо бот опублікував помилку або змінився дизайн — оберіть дату, і бот замінить картинку й текст у вже
  надісланих повідомленнях на актуальну версію. Підписники сповіщень не отримують.
- **Оголошення.** Пости обленерго без графіка, але важливі для людей (скасування ГПВ, аварійні відключення, «завтра без
  відключень»), бот сам не публікує — надсилає власникам із кнопками «📣 Опублікувати всім / 🙈 Пропустити».
  Рішення одного власника видно іншому. Пости для бізнесу (ГОП) і новини відсіюються.
- У кожному графіку є рядок «Своя черга: cherkasyoblenergo.com/off» для тих, хто не знає своєї підчерги.

## Надійність

- **Сповіщення власникам.** Бот пише всім власникам в особисті, якщо: не розпізнав рядок графіка (новий
  формат посту), графік опубліковано картинкою, канал обленерго недоступний понад 10 хв (і коли знову
  доступний), бот втратив доступ до каналу чи групи. Однакові сповіщення — не частіше ніж раз на годину.
- **Бекап бази.** Щодня о `BACKUP_HOUR`:05 (за замовчуванням 04:05 за Києвом) бот надсилає `bot.db` кожному
  власнику файлом; `/backup` — те саме на вимогу. Відновлення: покласти файл на сервер як
  `/root/GVSTelegramBot/data/bot.db` і виконати `docker compose restart`.
- **Сторожовий таймер.** Якщо цикл перевірки каналу завис або впав, бот сам завершується, а Docker
  (`restart: unless-stopped`) одразу запускає його знову; власники отримують «🔁 Бот перезапускається».
- **Зовнішній нагляд (необов'язково).** Якщо вимкнеться сам сервер, бот повідомити не зможе. Для цього є
  безкоштовний [healthchecks.io](https://healthchecks.io): створіть check «lampochka» (Period 2 min,
  Grace 5 min), у Integrations підключіть Telegram, скопіюйте Ping URL у `.env` як `HEALTHCHECK_URL=…`
  і виконайте `docker compose restart`. Бот «відмічається» після кожної вдалої перевірки каналу; якщо
  тиша триває понад 5 хв — healthchecks напише вам.

## Що сказати друзям

> Напиши боту @ваш_бот `/start` — я підтверджу доступ, і графіки приходитимуть тобі в особисті.
> Хочеш у свій канал чи групу? Після `/start` бот дасть кнопки «у канал» / «у групу».

## Команди

| Команда | Що робить |
|---|---|
| `/start` | підписатися + посилання, як додати бота в канал/групу |
| `/now` | графік на сьогодні (і на завтра, якщо вже опубліковано) |
| `/stop` | відписатися (у групах тільки для адмінів) |
| `/stats` | кількість підключених чатів і стан перевірок (лише власник) |
| `/users` | хто має доступ / чекає, кнопки дозволити й забрати (лише власник) |
| `/post` | опублікувати актуальний графік у вибраний канал чи групу — кнопками (лише власник, в особистому чаті з ботом) |
| `/my` | моя черга: персональний рядок у графіку, нагадування за 30/20/15/10 хв (лише власник) |
| `/fix` | замінити картинку й текст уже надісланих графіків за обрану дату на актуальну версію (лише власник) |
| `/pin` | увімкнути/вимкнути закріплення графіка по каналах і групах (лише власник) |
| `/remind` | нагадування в канал/групу за 30/20/15/10 хв до відключення, окремо для кожного чату (лише власник) |
| `/backup` | надіслати копію бази всім власникам (лише власник) |

## Для розробки (Mac)

```bash
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
.venv/bin/python -m pytest -q        # тести
.venv/bin/python -m bot.render_demo  # demo.png з останнього графіка
.venv/bin/python -m bot.main         # запуск бота локально (потрібен .env)
```

Тести також запускаються на GitHub після кожного push (вкладка Actions). Шрифт Inter (ліцензія OFL) лежить
у `fonts/`, щоб картинка була однаковою на Mac і на сервері.

Структура: `bot/scraper.py` читає канал, `parser.py` розбирає текст, `render.py` малює картинку,
`formatter.py` формує підпис, `publisher.py` перевіряє канал і робить розсилку, `handlers.py` обробляє команди,
`access.py` — приватний режим, `alerts.py` — сповіщення власникам, `maintenance.py` — бекапи,
`storage.py` працює з SQLite (`data/bot.db`).
